# C-Job 社交平台发布素材包

这套素材围绕 C-Job 的真实使用场景制作，适合小红书笔记、B 站视频、动态和评论区回复。

## 产品定位

C-Job 是一个秋招投递助手，主要解决秋招期间岗位消息太多、资料分散、不同岗位不知道该用哪些经历投递的问题。

- 求职群里的岗位消息很多时，可以先浏览，遇到合适的岗位就保存链接，之后再慢慢补资料和投递。
- 内置经历和项目数据库，可以保存个人经历、项目，以及求职过程中经常需要填写的内容。
- 生成简历时可以结合 JD 自动匹配相关项目经历，再根据不同岗位选择合适的经历投递。
- 岗位、经历和项目资料都保存在本地。
- 通过 GitHub 私有仓库提供远程同步，方便在多台设备之间同步岗位以及经历与项目资料。

## 统一介绍

> C-Job 是一个秋招投递助手。群里的岗位消息太多时，可以先把合适的链接保存下来，之后再慢慢补资料；经历和项目统一存进数据库，生成简历时结合 JD 自动匹配，再为不同岗位选择合适的经历。数据保存在本地，也可以通过 GitHub 私有仓库同步到多台设备。

## 表述边界

建议说“自动匹配项目经历”“辅助整理和投递”，不要说“保证拿 offer”“自动投遍全网”或“替你完成所有投递”。
