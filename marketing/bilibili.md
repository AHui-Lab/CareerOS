## 视频简介

这是我做的 C-Job，一款秋招投递助手。

秋招期间，求职群里的岗位消息经常成片地来。来不及马上投时，可以先浏览，把合适的招聘链接保存下来，之后再慢慢补资料、看 JD、选经历和推进投递。

C-Job 内置经历和项目数据库，可以保存个人经历、项目，以及求职过程中经常需要填写的内容。生成简历时，可以结合 JD 自动匹配项目经历，再针对不同岗位选择不同的经历组合。

岗位、经历和项目资料都保存在本地；如果需要多台设备使用，也可以通过 GitHub 私有仓库进行远程同步。

这不是一个替你完成所有投递的工具，而是把秋招岗位和求职资料整理得更顺手一些。视频中的资料使用示例或脱敏内容。

## 3–5 分钟视频结构

### 00:00–00:25 为什么做 C-Job

从求职群消息成片出现讲起：很多岗位值得投，但不一定有时间当场填完资料；如果没有统一的保存入口，之后很容易找不到。

### 00:25–01:15 先保存岗位

演示保存招聘链接，查看岗位列表，补充公司、岗位、类别、JD 和投递状态。说明“现在没空投”不等于“放弃这个岗位”。

### 01:15–02:05 经历和项目数据库

展示项目、实习、科研等经历，以及常见求职填表内容。说明数据库保存的是可以长期复用的个人资料，之后写简历和填表都可以直接查看。

### 02:05–03:05 JD 匹配项目经历

打开一个岗位，结合 JD 自动匹配相关项目经历，展示匹配结果和项目选择。强调不同岗位可以选择不同经历，最终选择由自己确认。

### 03:05–03:45 生成岗位简历

勾选经历并生成简历，演示预览和导出。说明简历不是固定的一份，而是根据岗位组合经历后生成的版本。

### 03:45–04:30 本地保存与多设备同步

说明岗位、经历和项目资料保存在本地；需要多台设备时，可以配置 GitHub 私有仓库进行远程同步。

### 04:30–05:00 收尾

总结 C-Job 的使用顺序：看到岗位先保存，有时间再补资料，投递前结合 JD 选择经历并生成简历。
