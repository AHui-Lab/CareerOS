# 平台发布前检查清单

## 共同检查

- [ ] 岗位、公司、邮件和简历截图使用示例或脱敏数据。
- [ ] 遮挡姓名、手机号、邮箱、身份证号、证件照、地址、内推码和账号信息。
- [ ] 不使用“保证拿 offer”“投递成功率翻倍”“第一”“最好”“唯一”等结果承诺或绝对化表述。
- [ ] 不把“自动匹配项目经历”写成“自动替你完成全部投递”。
- [ ] GitHub 同步演示只展示私有仓库配置界面，不展示仓库地址、用户名、访问令牌或个人资料内容。
- [ ] 不展示真实公司内部 JD、未公开招聘信息或他人隐私。
- [ ] 封面、标题与视频/笔记内容一致，不用无关内容吸引点击。

## 小红书

- [ ] 以个人开发过程、真实使用场景和功能演示为主。
- [ ] 简介、正文、评论、图片和视频中不放微信号、二维码、网址、邮箱或“主页联系”等站外引流信息。
- [ ] 不使用“评论区回复 1 领取资料”“点赞送资料”等诱导互动方式。
- [ ] 不使用谐音、变体字或网络黑话规避审核。
- [ ] 如后续进行商业合作，按小红书官方合作/报备流程执行，并按要求进行商业声明。

## B 站

- [ ] 标题和封面准确描述内容，封面与视频主题一致。
- [ ] 视频、简介、评论、弹幕和动态中不放未经平台合规流程的二维码、微信号、QQ、手机号、公众号、网盘或交易链接。
- [ ] 如属于商业推广，使用 B 站官方商业化/推广流程，并完成必要的商业声明。
- [ ] 不把视频主要内容做成引导用户到站外注册、关注、交易或消费。
- [ ] 音乐、截图、字体和第三方素材已获得授权或符合平台使用规则。

## 口径替换表

| 不建议 | 建议 |
| --- | --- |
| AI 自动投简历 | 结合 JD 自动匹配项目经历 |
| 一键拿 offer | 先保存岗位，再慢慢准备投递 |
| 自动投遍全网 | 岗位链接集中保存和管理 |
| 全网自动填表 | 保存常用的求职资料和填表内容 |
| 所有岗位都用同一份简历 | 根据不同岗位选择不同经历生成简历 |
| 资料上传云端 | 资料保存在本地，也支持通过 GitHub 私有仓库同步 |
