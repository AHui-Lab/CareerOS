# Obsidian retirement policy

As of JobPilot 0.3.0, Obsidian is not a runtime data source.

Historical Obsidian/Resume repositories may be used only as migration inputs. Migration must be review-first and should classify source material into:

- verified career facts -> CareerVault draft experiences;
- evidence/attachments -> linked CareerVault files;
- interview/learning notes -> not resume facts;
- ideas/future plans -> Inbox or skipped;
- duplicated resume versions -> corroborating sources only, not duplicate experiences.

No JobPilot endpoint should import an Obsidian folder directly.
