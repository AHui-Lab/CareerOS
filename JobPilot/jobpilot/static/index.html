    CareerOS 通过 IMAP 读取邮件。配置前先在邮箱网页端开启 IMAP，并按邮箱类型填写登录密码、客户端授权码或应用专用密码。

    GET STARTED

    新手教程

    CareerOS 的基本使用流程：

    1在“经历和项目”中维护真实经历、技能、成果与证据。
    2在“校招岗位”中导入岗位，并人工确认 JD。
    3在“简历中心”选择岗位，分析 JD 与经历的匹配情况。
    4选择合适经历生成简历，再使用浏览器助手辅助填表。

    ABOUT CAREEROS

    软件说明

    CareerOS 是本地优先的个人求职工作台，包含岗位管理、邮件跟踪、经历和项目管理、JD 分析、简历生成和浏览器辅助填表。

    岗位和邮件数据保存在本机；生成简历前请始终人工检查内容，不会自动提交网申。

    PRIVATE PROFILE

    本地私密资料

    身份证号、证件照、紧急联系人等只保存在本机 JobPilot 数据库和私密资料目录，不会写入 CareerVault 或 Git。
