## 一、单选题

### 第1题（单选题）
**题目：** （原卷单选第6题）在智能相机嵌入式开发中，关于进程间通信（IPC）方式的选择，以下说法错误的是（ ）

**选项：**
- A. 共享内存是速度最快的 IPC 方式，适合传输大块图像数据
- B. 共享内存通常需要配合信号量或互斥锁使用以保证数据一致性
- C. 信号量通常用于进程间的大数据量传输
- D. 管道（Pipe）适合父子进程之间的简单数据传输

**答案：C**
**解析：** 信号量用于同步与互斥控制，本身不携带大数据载荷。大块图像数据应走共享内存（配合信号量/互斥锁同步）。管道适合父子进程简单字节流；选项 A/B/D 描述均正确，故错误的是 C。

### 第2题（单选题）
**题目：** （原卷单选第9题）volatile 关键字的主要作用是：

**选项：**
- A. 保证变量读写具有原子性
- B. 自动为变量加锁
- C. 保证多个线程同时访问时不会发生竞争
- D. 防止编译器优化对该变量的访问

**答案：D**
**解析：** volatile 只告诉编译器该值可能被硬件/中断/其他执行流意外改变，禁止把读写优化掉或缓存到寄存器。它不提供原子性、不加锁、也不解决多线程竞争（那是原子操作或锁的职责）。图中选中 C 为误选。

### 第3题（问答题）

**解析：** 参考要点：[] 是 POSIX test 命令，是外部/内建命令，变量未加引号时会发生单词分裂和通配符展开，比较用单等号 =，逻辑组合需用 -a/-o。[[]] 是 bash/ksh 的关键字，支持模式匹配（==/=~）、逻辑运算符 &&/||、对变量更安全，可防止大部分词法分裂问题。脚本需可移植到 sh/dash 时用 []；bash 脚本里条件复杂时优先 [[]]。

面试常考点：可移植性 vs 功能、变量引用安全、字符串模式匹配、逻辑运算写法。

### 第4题（问答题）
**题目：** （原卷问答第6题）在单片机的裸机开发中，如果要让一个耗时任务精准地按 1000ms 的间隔周期性地执行，需要如何设计？

**答案：** 参考要点：用硬件定时器（SysTick/Timer）产生固定节拍，中断里只置标志或递减计数，主循环/状态机里消费标志去执行耗时任务；不要在中断里跑长任务。…

**解析：** 参考要点：用硬件定时器（SysTick/Timer）产生固定节拍，中断里只置标志或递减计数，主循环/状态机里消费标志去执行耗时任务；不要在中断里跑长任务。若任务执行时间可能超过周期，需记录"理论唤醒点"而不是"执行完再延时 1000ms"，用相位累加/绝对时间比较（`if (now - last >= 1000) { last += 1000; ... }`）避免累积漂移。必要时把耗时任务拆片，或用 DMA+中断分担 CPU。

核心是"定时基准与执行解耦"+"用绝对时间防漂移"+"耗时任务不进中断"。

**解析：** 参考要点：1）用示波器/逻辑分析仪看物理层波形——时钟/片选是否完整、电平与上拉是否正确、是否有 NACK/超时；2）核对寄存器地址、读写位、字节序（MSB/LSB first）、寄存器宽度与多字节读协议，是否有 dummy byte；3）检查时序参数是否在器件手册范围内（建立/保持时间、时钟频率），以及是否有上电初始化/复位未完成就访问；4）交叉验证——读只读 ID 寄存器、写后回读已知寄存器、换一块已知好板或另一台主机对比；必要时检查电源噪声、总线冲突（多主机/从机地址冲突）。

标准排查链：物理层 → 协议/寄存器映射 → 时序与初始化 → 对照实验隔离软硬件。
