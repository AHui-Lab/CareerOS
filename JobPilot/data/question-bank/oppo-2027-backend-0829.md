### 题目1：没有闰月

时间限制：1秒

空间限制：262MB

题目描述：

闰年有 366 天，多出的这一天是二月的 29 日。

然而，小歪在书写日期的时候，错误的将今年记成了闰年，所以他的 2 月依旧有 29 天，且三月及以后的全部日期都往后顺延了一天。

小歪需要你帮助他修复这个错误——对于他所给出的格式为 MM/DD 的日期，请你输出正确的日期。

输入描述：

第一行输入一个整数 n (1 ≤ n ≤ 366)，表示小歪给出的日期数量。

接下来 n 行，每行输入一个长度为 5 的字符串 s，表示小歪给出的日期。保证 s 的格式为 MM/DD 且给出的日期是闰年中的合法日期，其中 1 ≤ MM ≤ 12，1 ≤ DD ≤ 31。

输出描述：

输出 n 行，每行输出一个长度为 5 的字符串，表示正确的日期。

示例：

输入：

```
3
02/28
02/29
03/01
```

输出：

```
02/28
03/01
03/02
```

### 题目2：环形二进制序列

时间限制：1秒

空间限制：262MB

题目描述：

给定一个长度为 n 的环形二进制序列 a₁, a₂, ..., aₙ，其中 aᵢ ∈ {0, 1}，并约定 aₙ₊₁ = a₁。在该环上定义 n 条有序边 E₁, E₂, ..., Eₙ，其中边 Eᵢ 连接相邻状态 aᵢ → aᵢ₊₁。

定义每条边的贡献如下：

- 若 aᵢ = 0 且 aᵢ₊₁ = 1，则 Eᵢ 的贡献为 +1（升沿）
- 若 aᵢ = 1 且 aᵢ₊₁ = 0，则 Eᵢ 的贡献为 -1（降沿）
- 若 aᵢ = aᵢ₊₁，则 Eᵢ 的贡献为 0

对任意起点 s (1 ≤ s ≤ n) 和步数 k (k ≥ 0)，定义一个长度为 k 的窗口为：从环形边序列自 Eₛ 起连续取 k 条边（遇到 Eₙ 后继续从 E₁ 接续）。该窗口的得分为这 k 条边贡献值之和；若 k = 0，窗口为空，其得分为 0。

请计算所有起点 s 的窗口得分中的最大值。

输入描述：

每个测试文件包含多组测试数据。第一行输入一个整数 T (1 ≤ T ≤ 10⁵) 表示数据组数。每组测试数据描述如下：

- 第一行输入两个整数 n, k (1 ≤ n ≤ 2×10⁵, 0 ≤ k ≤ 10¹⁸)
- 第二行输入 n 个整数 a₁, a₂, ..., aₙ (aᵢ ∈ {0, 1})

保证所有测试数据的 n 之和不超过 2×10⁵。

输出描述：

对于每组测试数据，输出一个整数，表示所有起点的窗口得分的最大值。

示例：

输入：

```
2
5 3
0 1 1 0 0
6 100
1 0 1 0 1 0
```

输出：

```
1
0
```

说明：

在第一组数据中：

- 各边贡献为：E₁: +1, E₂: 0, E₃: -1, E₄: 0, E₅: 0
- 取连续 3 条边的得分最大为 1（例如起点 s = 4 或 s = 5）
