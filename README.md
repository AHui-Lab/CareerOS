# CareerOS

CareerOS 是个人求职管理工作台，由两个相互协作的功能模块组成：

- `JobPilot`：校招岗位、岗位解析、投递跟踪、岗位简历和浏览器助手。
- `CareerVault`：经历与项目、教育背景、成果证明和可用于简历的事实资料。

## 启动

进入 `JobPilot` 目录，运行：

```bat
career-os.bat
```

然后打开 <http://127.0.0.1:8765>。统一启动器会启动两个本地服务：

- 求职管理：`127.0.0.1:8765`
- 经历资产：`127.0.0.1:8766`
