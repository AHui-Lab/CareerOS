# CareerOS

本地优先的个人求职工作台，把岗位收集、经历整理、简历制作、面试准备、日程跟进和 Offer 决策连接起来。

**当前版本：v0.7.0 · 2026-10-12**

系统由 `JobPilot`（求职管理）和 `CareerVault`（经历资料库）两个服务组成，共用一个安装入口、启动入口和工作台。基础功能无需 AI API 密钥；个人数据保存在本机，可另行配置加密私有仓库同步。

## 最新版功能

界面按“总览 → 模块列表 → 记录详情 → 更多设置”逐步展开。桌面总览直接呈现八个核心功能入口，保留精简的进展、重点行动和近期日程；完整列表、月历和复杂字段按需打开。

| 功能区域 | 可以做什么 |
| --- | --- |
| 总览与日程 | 查看八个模块入口、求职进展和优先事项；紧凑展示今天、明天、后天的前 3 项安排，包括公司、时间及面试 / 笔试 / 签约类型，点击查看完整日历与行动列表 |
| 岗位管理 | 导入并核对 JD，查看公司、岗位、地点、JD 摘要、投递日期、关联简历、准备材料和下一步；支持列表、看板、紧凑视图及搜索筛选 |
| Offer 管理 | 独立记录录用条件，也可从岗位带入基础信息；分组补充待遇、合同与证据，比较 2–4 份 Offer，上传附件、导出 CSV、归档与恢复 |
| 资料库 | 整理教育、项目、实习、科研、获奖、专利、论文及证明材料；从“名称、本人贡献、结果”开始录入，更多细节按需展开，区分草稿和可用于简历的事实 |
| 简历工作室 | 按“确认目标 → 选择经历 → 核查与生成”制作岗位简历；保存版本和资料快照，预览并导出中文 PDF、DOCX 或辅助填表数据 |
| 面试准备 | 为岗位关联准备空间，维护 JD、团队信息、任务、笔记和材料，并记录面试经验与复盘 |
| 笔试题库 | 管理试卷与题组、题目、答案和复习资料 |
| 邮件跟踪 | 通过 IMAP 检查招聘邮件，人工确认后关联岗位；支持忽略与恢复 |
| 设置与数据 | 配置服务、AI、浏览器助手、备份和私有仓库同步，使用兼容工具与故障诊断 |

### Offer：适合国内招聘的待遇记录与比较

Offer 在左侧导航、总览和全局搜索中都有独立入口。先录入公司、岗位等基本信息，再逐步补充六组细节：**薪酬结构、社保公积金与福利、工作安排与生活成本、团队与发展、合同与签约、沟通与个人判断**。目前包含 94 个细节字段，并支持自定义比较维度和可增删的待遇阶段。

- **保留原始薪资口径**：分别记录固定月薪与保证薪数、已确认固定年现金、平均 / 参考年收入、年收入区间，以及税前 / 税后、对应人群和包含项目。央国企给出的“平均年薪”或区间不会自动变成月薪或保证收入。
- **分阶段记录**：学生实习、见习、劳动合同试用期、转正及其他阶段分别填写期限、固定金额、折扣与明确基数、年收入参考、协议和来源。只有确认金额和时长后才计算已知阶段工资；首年汇总需手动选择计入阶段，并标明部分已知或完整 12 个月。
- **分清现金与福利**：保证现金、浮动奖金情景、一次性签字 / 安家费、股权及公积金分别展示；明确固定年现金总额后避免重复相加。单位公积金优先采用已核实的实际月缴额，其次才按基数与比例估算。
- **记录核实条件**：合同及发薪主体、试用与转正标准、三方 / 两方、违约与服务期、竞业、工时、年金、宿舍房补、政府人才补贴资格及兑现条件。待核实、口头、书面信息及来源独立记录。
- **比较并跟进**：2–4 份 Offer 按组对照并突出差异，同名自定义维度对齐；回复截止和签约日期联动日程。支持 PDF、图片、DOCX、TXT 附件（每份 Offer 最多 20 个，每个不超过 10 MB），附件随完整数据库备份保存。

模块内提供 13 个国内参考来源，区分政策年度、城市和适用范围；地方待遇需按本人条件核实。系统展示已确认金额与个人估算，不自动计算个税或替用户作出录用决策。

详见 [Offer 使用说明](docs/Offer-评估维度与使用说明-20261011.md) 和 [国内参考与分阶段薪资](docs/Offer-国内参考与分阶段薪资-20261011.md)。

### 岗位整理与渐进式录入

岗位的**整理状态**与**投递进度**分别保存。默认关注进行中的岗位，可单条或批量移至“稍后再看”“不考虑”“已结束”，填写回看日期与备注，之后恢复；批量整理支持短时撤销，不删除 JD、历史和关联材料。到期回看进入首页行动，已搁置岗位的旧行动不再占据重点区域。

岗位导入先预览、再核对保存；登录后的个人中心若无法提取 JD，可以手动补充岗位描述，错误提示会保留输入并说明问题。资料库默认精简录入，保存后回到列表；原始长文、扩展字段、关联经历与证明材料继续保留。

### 一致的使用体验

统一页面风格、浅色 / 深色外观、手机导航、键盘焦点和未保存编辑提示。使用 `⌘K` / `Ctrl+K` 搜索本机岗位、Offer、经历、简历、准备资料和题目。Chrome / Edge 浏览器助手支持常见表单的辅助填写，提交前由用户检查并操作。

## 快速开始

需要 Python 3.10 或更高版本。先克隆仓库：

```sh
git clone https://github.com/AHui-Lab/CareerOS.git
cd CareerOS
```

### macOS

首次双击根目录 `install.command`，之后双击 `start.command`；停止时双击 `stop.command`。终端也可执行：

```sh
./install.command
./start.command
# 使用结束后停止服务
./stop.command
```

安装器可使用检测到的 Codex Python 运行时，否则使用系统 `python3`；设置 `CAREEROS_PYTHON` 可指定解释器。两个服务共用根目录 `.venv`，重复启动会复用本目录已运行的服务。

### Windows

首次双击根目录 `install.bat`，之后双击 `start.bat`；停止时使用 `stop.bat`。安装器会为两个模块安装依赖，不需要分别安装。

```bat
install.bat
start.bat
REM 使用结束后停止服务
stop.bat
```

### 访问与可选配置

启动器会打开 <http://127.0.0.1:8765>。通过左侧“资料库”使用 CareerVault，无需另外打开页面。健康检查地址：

- JobPilot：<http://127.0.0.1:8765/api/health>
- CareerVault：<http://127.0.0.1:8776/api/health>

两个接口都返回 `"ok": true` 即表示服务正常。要使用 AI，在 `JobPilot/.env` 中配置兼容服务地址、API 密钥和模型，参考 `JobPilot/.env.example`。浏览器助手需在 Chrome / Edge 扩展开发者模式中加载 `JobPilot/extension`。

仓库现有经历资料需核对并替换为自己的真实经历。正式简历使用 CareerVault 中可用于简历的事实；旧 JobPilot 资料仅作为历史恢复和明确的离线兼容入口。

## 更新已有安装

停止服务后更新代码并补齐依赖，再启动：

macOS：

```sh
./stop.command
git pull --ff-only origin main
./install.command
./start.command
```

Windows：

```bat
stop.bat
git pull --ff-only origin main
install.bat
start.bat
```

安装器不会删除本地数据，新增数据库结构兼容已有记录。更新后刷新浏览器。若 Git 提示本地经历文件有改动，请先保留这些改动，不要用强制覆盖来更新。

## 数据、备份与隐私

| 内容 | 保存位置 |
| --- | --- |
| macOS JobPilot 数据库（含 Offer 及附件） | `.local-data/jobpilot/jobpilot.db` |
| Windows JobPilot 默认数据库 | `%LOCALAPPDATA%\JobPilot\jobpilot.db` |
| 经历与公开资料 | `CareerVault/vault` |
| CareerVault 私密资料与证件照 | `CareerVault/private` |
| AI 配置 | `JobPilot/.env` |
| macOS 日志与启动状态 | `.runtime` |

开发时可用 `JOBPILOT_DATA_DIR` 指定独立数据目录。数据库、私密资料、运行文件和 `.env` 不应提交到公开代码仓库；经历文件仍需自行检查 Git 跟踪状态和公开范围。

私有同步使用**另一个私有 GitHub 仓库**：

1. 创建私有仓库并确保本机 Git 能访问。
2. 在“设置和帮助 → 私有仓库同步”填写地址、分支和同步口令。
3. 提交当前数据；另一台电脑用相同配置检查并接受远程更新。

远端保存加密快照，包含 JobPilot 数据库、CareerVault 经历、私密资料和证件照。启动时只检查更新；接受远端前由用户确认，可回滚误接受。启用关闭自动同步后，停止服务会尝试提交快照。请妥善保管同步口令。

## 常见问题

- **缺少依赖或 `cryptography` 报错**：重新运行当前平台的根目录安装脚本。
- **启动失败或端口冲突**：确认 `8765` / `8776` 没被其他程序占用，检查日志；macOS 查看 `.runtime/JobPilot.log`、`.runtime/CareerVault.log`，Windows 查看各模块 `.runtime` 下的错误日志。启动器只停止它管理的进程。
- **岗位导入内容不完整**：在预览中补齐公司、岗位与 JD；个人中心、登录页和招聘首页可能不包含具体岗位正文。
- **私有同步无法访问仓库**：核对仓库地址和 Git 认证；可用 `git ls-remote <私有仓库地址>` 检查，不要把口令或凭据写进公开文档。
- **表单未完全填写**：确认本地服务运行且扩展有页面权限；复杂动态下拉、重复经历行及照片上传仍需人工检查。

## 开发与验证

```sh
# 在仓库根目录，使用独立测试数据目录
JOBPILOT_DATA_DIR="$PWD/.runtime/tests/jobpilot" PYTHONPATH=JobPilot \
  .venv/bin/python -m unittest discover -s JobPilot/tests -v
PYTHONPATH=CareerVault \
  .venv/bin/python -m unittest discover -s CareerVault/tests -v

for test in JobPilot/tests/*.cjs CareerVault/tests/*.cjs; do node "$test"; done
```

Windows 可使用模块虚拟环境中的 Python，并设置同名环境变量后执行相应测试。JavaScript 测试需要 Node.js。测试覆盖 Offer 口径与阶段计算、附件、归档、日程联动、岗位整理、导入错误与资料录入；浏览器验收记录见下方文档。
