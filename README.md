# CareerOS

CareerOS 是个人求职管理工作台，由两个相互协作的功能模块组成：

- `JobPilot`：校招岗位、岗位解析、投递跟踪、岗位简历和浏览器助手。
- `CareerVault`：经历与项目、教育背景、成果证明和可用于简历的事实资料。

## 启动

进入 `JobPilot` 目录，运行：

```bat
career-os.bat
```

然后打开 <http://127.0.0.1:8765>。统一启动器会启动两个本地服务，但用户只需要使用 CareerOS 这一个界面：

- 求职管理：`127.0.0.1:8765`
- 经历资产：`127.0.0.1:8766`

在 CareerOS 左侧点击“经历资产”，即可在同一工作区中使用 CareerVault 的经历库、个人资料和配置；两个服务仍保持独立的数据边界，便于备份和故障隔离。

## 当前目录约定

两个模块暂时保留各自的数据库和 API/插件兼容边界；代码统一由本仓库的根目录 Git 历史管理。
