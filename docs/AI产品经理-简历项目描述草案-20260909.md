# AI 产品经理简历项目描述草案

依据 2026-09-09 本地材料整理。以下为候选文案；既有经历来自经历库记录，新增项目职责、起止时间需本人核对。本次没有覆盖经历库、生成 Word 或将文案标为已审核。不要把尚未执行的实验写入投递版。

## 1. 简历结构

建议一页：教育 → 相关实习 → 两个主项目 → 技能与精选成果。主投 AI 应用时用 CareerOS + RAG 或助手（选证据更完整的）；硬件岗位换 miniLED + 合越；游戏 AI 岗位换游戏案例。

抬头可写：**AI 产品经理（校招）｜AI 应用、RAG 与 Agent 实践**。

真实公司职务保留“实习生”等原称，不能改写成已任职的“AI 产品经理”。个人项目若实际负责需求、方案和验收，可写“个人项目｜产品设计与实现（AI 辅助开发）”。

## 2. CareerOS｜个人求职工作台

以下交付能力有当前文档和部分代码支持，起止时间与个人职责仍需本人补充。

- 围绕经历整理、岗位匹配与定向简历制作流程，设计并实现本地求职工作台，串联经历资产、JD 分析、简历版本与导出。
- 将已审核经历作为定向简历输入，区分源事实与生成结果，保留经历来源及版本快照，为人工核对和修改提供依据。
- 实现网申辅助填表并保留最终人工检查与提交环节，处理通用字段，明确复杂表单仍需人工补充的边界。

不写“彻底消除幻觉”“提高面试率”“已有 N 用户”。具备事实源和提示约束不等于输出已经通过质量验证。

后续有实测记录时，用一条结果替换功能条目：

> 在【人数】名目标用户、【任务数】次任务中，对比原有方式与当前版本，人工核对完成耗时中位数为【A/B】，可提交完成数为【a/n、b/m】；定位【具体问题】，通过【改动】降低【错误/返工】，首次整理成本为【值】。

这一模板未填前不能用于投递。

## 3. 龙虾小助手｜微信任务与记账助手

依据当前 README 与测试线索整理；如写“负责”，需对应本人实际承担的设计/实现/验收。

- 基于 OpenClaw 原生会话与工具调用，接入本机任务及记账服务，划分模型理解与确定性业务执行的职责。
- 为任务操作设计幂等、版本检查、修正与撤销机制，并为相关逻辑及工具桥接编写测试，覆盖重复请求与更新恢复等场景。
- 将提醒创建与调度结果关联，保留执行失败和单机运行边界；当前仍需补齐真实微信渠道的到期送达与改期回归记录。

第三条适合面试/作品集说明，简历版空间不足可省略，但不能替换成“实现稳定实时提醒”。不将 OpenClaw 自带 Agent Loop、记忆或渠道能力描述为独立自研。

## 4. RAG｜知识库问答工具（先核对版本）

- 围绕 Obsidian 笔记检索与回答核查场景，设计知识库问答交互，通过来源跳转与检索明细提供原文核对入口。
- 【找到代码和案例后使用】针对专有术语检索问题，调整检索策略并引入混合检索，记录命中证据与生成回答，定位检索和生成环节的不同失败原因。
- 【找到评测集和记录后使用】建立覆盖【实际类别】的【题数】题评测集，固定【版本/模型/文档】比较【基线与改动】，报告【真实指标】及未解决的边界。

必须先解决：IndexedDB 与 ChromaDB/共享后端对应哪个版本；五类文档是否仍在当前版可用；本地/云端嵌入与生成分别如何配置。未核实前不写“数据不出本机”。

## 5. 合越实习｜多传感器融合动作采集与交互

- 面向游戏交互与康复训练原型，负责 BLE 通信方案与 Unity 端应用开发，协同嵌入式端制定数据包格式，完成多传感器接入、姿态解析与三维动作映射。
- 推动经典蓝牙 SPP 向 BLE 迁移，通过消息流水号开展丢包测试，据测试结果选定 100 Hz 传输频率，形成通信稳定性与更新频率的方案取舍。
- 针对手型、佩戴位置及初始姿态差异，设计在线归一化与静态校准，完成双手交互和现场演示。

经历库记录 50/100 Hz 丢包率为 0%，200 Hz 为 2.63%。若使用这些数字，注明为“当次测试”，并准备测试时长、总包数及环境；不外推长期运行零丢包，也不改写成康复疗效。

## 7. 游戏与科研的可替换条目

游戏：现有经历记载“确定性 Game Core 裁决交易等事实，LLM 负责对话与叙事”，这是可深挖的权限边界案例。先附实际构建、规则测试和模型联调记录，再写已交付章节/角色/道具数量；旧 Notes 与 resume_ready 状态需同步复核。

miniLED：强调器件接触验证、16 路电流采集与自动检测系统的完整交付；专利使用“发明专利申请已公布，第二发明人”，不写已授权。

## 8. 每条简历的五项核对

1. 有对应源文件、版本或实物吗？
2. 动词准确反映个人贡献吗？独立、主导、协同不能互换。
3. 原型、内测、发布、长期运行是否区分？
4. 数字的分母、条件与日期能解释吗？
5. 能在 90 秒内讲出问题、决策、结果及一个限制吗？

没有量化提升时，保留真实取舍和交付范围即可。简历不需要把每条都写成完整故事；展开证据放在作品集和面试里。
