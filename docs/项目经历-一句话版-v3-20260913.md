# 项目经历 · 一句话版 v3（2026-09-13）

> 9-13 HR 面对面后的结论：v2 还是太长。这版只改一件事：**每个项目，简历一行，口述一句。**
> 所有细节降级为"被追问才说"。v2《HR一眼版》《极简表述稿》不再做日常用，降为追问层备查。

## 为什么 v2 还是失败

- v2 每条 bullet 是"冒号展开句"：一个信息点后跟一串技术词（双倍召回、阈值过滤、来源去重）。HR 扫不懂，你口述时也想整句背出来，一说就乱。
- 口述乱的根源不是没骨架，是**默认输出量太大**。改法：默认输出 = 一句，说完就停。
- HR 初筛只判断三件事：**做过什么东西 / 角色是不是实的 / 有没有做成过**。技术名词对 HR 是噪音。

## 防说乱纪律（比内容更重要）

1. **一句话说完就停，数 3 秒再考虑补充。** 冷场不是你的失败，抢话填补才是乱的开始。
2. **技术词只在对方先提时用。** BLE、EKF、检索策略——HR 不问就不说。
3. 被问"你具体做了什么"，答一句证据："方案是我提的 / 测试是我做的 / 问题是我定位的"。
4. 每天对着手机录一遍四句话（共 40 秒），直到脱口而出、不经过脑。
