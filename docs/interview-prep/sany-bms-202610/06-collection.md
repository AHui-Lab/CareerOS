## 资料收集规则

- 公司产品先查官网与官方手册；新闻记录事件日期，不能把历史产品当作最新配置。
- 技术先读芯片厂商、MCU 厂商、RTOS 官方文档；面经用于题目线索。
- 每条记录标题、URL、发布日期/版本、收集日期、关键事实和使用场景。
- 给结论标记“官方确认 / 媒体转载 / 个人面经 / 行业知识 / 待核实推断”。
- 对相冲突的参数先记录差异，不选择看起来更先进的一项当成真值。
- 继续更新资料时保留原始来源与本次检索日期。
