## 优先级

必须能讲：C/C++ 基础边界、RTOS 同步与调度、驱动/通信接口、时序与资源问题定位、单元/接口测试、可移植性；并能讲公司产品、BMS 总链路、SOC/SOH/SOP、保护、真实项目与限制。

应理解：预充、均衡、日志/故障注入、采集误差。RTOS 已在 JD 明确提出，提升到必须复习。

按 JD 再决定深度：AUTOSAR、Bootloader/OTA、UDS、功能安全流程、复杂 SOC 参数辨识。未确认汽车软件架构前，不把 AUTOSAR 当成必考重点。

## 45 分钟模拟流程

- 0–3 分钟：自我介绍，说明与岗位相关经历。
- 3–8 分钟：公司业务、储能与动力场景、BMS/PCS/EMS。
- 8–18 分钟：STM32 融合定位深挖，重点追问本人分工与验证。
- 18–28 分钟：SOC、均衡、保护、失效数据及预充。
- 28–36 分钟：C、UART/CAN、ISR/任务同步。
- 36–41 分钟：随机重启或通信失联故障题。
- 41–45 分钟：转方向动机、不会的问题、反问。

每题用 0/1/2 简单记录：0＝核心错误或无法回答；1＝方向正确但缺机制/边界；2＝机制正确且能说验证。它是练习自评，不是招聘通过概率。

## 第一次模拟题

- 你为何投三一锂能？目前了解哪些产品？
- BMS 怎样从采集数据走到保护执行？
- 你的 EKF 项目可以迁移到 SOC 哪些部分，哪些不能迁移？
- 一节电芯温度跳高，你怎样兼顾误报和真实故障？
- CAN 总线收不到报文，怎样逐层定位？
- ISR 与主循环共享一个结构体，怎么保持一致？
- 你做过的项目里最难定位的问题是什么？有什么证据？
- 假如录用，第一周怎么熟悉产品和代码？

## 面试前一页速记

- 公司：工程装备电动化与储能；ESG261＝261 kWh，ESX5016≈5 MWh，另有电塔、电兔和动力补能业务。
- BMS：采集 → 数据有效性 → 估算/诊断 → 限值/保护 → 执行反馈 → 通信与日志。
- SOC：电量状态；SOH：健康；SOP：有时间尺度和约束的功率能力。
- 算法：库仑计数会累积偏差；端电压不直接等于 OCV；模型要验证。
- 保护：阈值、时间、滞回、锁存、动作、反馈、恢复与日志。
- 通信：先物理层，再控制器/时序，再应用协议；最后值会过期。
- 我的证据：STM32F407 + UART + EKF；当次 RMSE ↓28.86%；关闭 2/4 基站仍定位；BLE 三档测试。
- 我的边界：尚无 BMS、CAN/RTOS 量产项目；学习与实际经历明确区分。
