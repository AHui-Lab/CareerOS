# BMS 从零入门

本章是通用技术学习材料。示例芯片和架构不代表三一锂能实际选型。

## 一句话解释

BMS 是电池管理系统：知道电池现在怎么样，判断还能怎样充放电，并在异常时限制或切断危险运行。

三个层次：采集事实 → 判断状态和边界 → 控制并验证执行结果。只上传电压不算完成管理；发出断开指令后没有检查执行反馈，也不算闭环。

## 系统链路

电芯/电池包 → 电压、温度、电流采集 → AFE/传感器 → MCU → 状态估算与诊断 → 限流、均衡、接触器/MOS 控制 → 对上层报告状态和允许限值。

- 电芯 Cell：最基本的电化学单元。
- 模组 Module、电池包 PACK、电池簇 Rack：系统组织层级；企业命名可能不同。
- AFE：模拟前端，承担精密采集等功能；部分器件集成独立保护和均衡控制。
- MCU：实现驱动、调度、通信、应用逻辑及算法。
- 分层 BMS：大系统可分为采集、簇控制、系统管理等层级；BMU/BCU/BAU 命名应以具体产品定义为准。

TI 的 BQ76952 是一个学习例子，面向 3–16 串电池并提供监测、保护和均衡支持；大储系统不能简单等同于一个此类芯片。[TI 官方产品说明](https://www.ti.com/product/BQ76952)

## 五个必须分清的量

| 名称 | 含义 | 易错点 |
| --- | --- | --- |
| SOC | 荷电状态，剩余电量相对可用容量的比例 | 不是“当前电压百分比” |
| SOH | 健康状态，可由容量衰减或内阻等指标定义 | 先说明定义，不只有一种公式 |
| SOP | 当前约束下可用充/放电功率能力 | 必须有时间尺度及电压、电流、温度约束 |
| Ah | 电荷容量单位 | 和 Wh 不是同一物理量 |
| Wh/kWh | 能量单位 | 功率 W/kW 乘时间才得到能量 |

估算 SOC 常用库仑计数、OCV 查表或模型方法，方法的取舍取决于传感器、初始状态、电池模型和工况。[ADI SOC/SOH 技术文章](https://www.analog.com/en/resources/technical-articles/a-closer-look-at-state-of-charge-and-state-health-estimation-tech.html)

## SOC 的最低可讲版本

规定放电电流为正，容量 Q 用 Ah、时间步长 dt 用秒，则简化离散积分：

```
SOC_next = SOC_now - I * dt / (Q * 3600)
```

SOC 用 0–1 表示。真实实现还需考虑充放电效率、可用容量变化、温度、电流零偏、初始 SOC 和校准条件。公式只说明基本积分，不能直接作为量产算法。

例：100 Ah 的电池以 10 A 放电 1 小时，理想状态下 SOC 减少 0.1，即 10 个百分点。电流零偏若持续存在，积分误差会累积。上下限裁剪可以避免数值越界，不能消除估算误差。

OCV 法利用充分静置后的开路电压与 SOC 关系。负载时的端电压受电流、内阻和极化影响，不能直接当 OCV；磷酸铁锂平台区的电压对 SOC 变化不敏感，要结合温度、滞回、静置条件和其他方法判断。[ADI 官方说明](https://www.analog.com/en/resources/technical-articles/a-closer-look-at-state-of-charge-and-state-health-estimation-tech.html)

## 你的 EKF 能迁移什么

能迁移的是状态估计框架：定义状态、建立预测模型和观测模型、分析噪声及异常观测、检查可观测性和验证结果。电池场景常需等效电路、OCV-SOC 曲线和参数辨识；这些与你的定位模型不同，需要重新学习。

推荐回答：“我在 STM32 定位项目里实际做过 EKF，熟悉预测、更新和噪声协方差的作用。SOC 估算的框架有相通处，但电池模型和参数是新问题，我不会把定位算法直接搬过去。”

## 均衡

串联电芯一致性会影响可用容量：充电时某节先到上限、放电时某节先到下限，都会限制整个串联组。

- 被动均衡：以电阻等方式消耗能量，电路通常更简单，需要控制发热。
- 主动均衡：在电芯或电芯与其他储能节点之间转移能量，设计更复杂。
- 控制考虑：进入/退出条件、温度、压差或状态差、工作模式、持续时长、采集干扰、硬件限制。
- 电压接近不意味着 SOC 必然相同；是否按电压均衡取决于化学体系和工况。

学习资料：[TI BQ769x2 均衡应用说明](https://www.ti.com/lit/an/sluaa81a/sluaa81a.pdf)。它针对特定器件，具体允许相邻通道等行为要读该器件手册。

## 保护不等于一个 if

典型监测项：过压、欠压、过流、短路、过温/低温、采集断线、通信失联。高压系统还需按设计考虑绝缘、互锁、接触器执行反馈等。

每个保护点要回答：检测依据是什么？数据是否有效？触发延时多少？恢复是否有滞回？故障是否锁存？执行什么动作？动作是否完成？记录什么上下文？

教学例：电芯电压超过某配置阈值持续一段时间进入故障；恢复要低于另一个阈值并满足恢复条件。数值应来自需求、电芯规格、硬件能力和验证，不随意给“行业统一阈值”。短路等快速故障可能依赖硬件路径，不能用普通软件滤波延时替代。

## 上下电与预充

预充用于限制连接直流母线电容时的冲击电流。通用思路：检查允许条件 → 建立预充路径 → 监测电池侧/母线侧状态和超时 → 满足条件后切换到主回路 → 确认反馈 → 退出预充。接触器顺序和阈值取决于具体电路，不能背一套固定顺序适用所有系统。

预充失败要查：负载短路、预充电阻/接触器异常、母线电压采集、执行反馈、超时配置、负载未隔离。失败时进入已定义的安全状态，不能无限重试。

## 一个软件模块划分练习

驱动采集、数据质量与校准、状态估算、故障诊断、保护状态机、通信、参数与日志、升级与启动。每个模块都需要定义输入、输出、周期/事件、失败条件和测试方式。

自测：解释“电压正常，但电流数据已经 5 秒没更新”为什么不能直接继续正常 SOC 积分和功率判断。
