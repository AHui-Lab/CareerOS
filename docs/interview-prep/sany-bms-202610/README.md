# 三一锂能 · BMS 嵌入式面试准备

建立时间：2026-09-30。预计面试：2026-10-06 或 2026-10-07，具体时间待确认。准备按 10 月 6 日倒排；不是已确认的面试日程。

## 从这里开始

你已有 STM32、C、多传感器采集、UART、EKF、上位机和实测验证的项目基础。此次准备的重点是补上电池业务、BMS 系统结构、保护逻辑与 CAN，再把已有经历讲成岗位能理解的能力证据。

目标：能讲清公司在做什么、BMS 软件如何工作、自己哪些经历可迁移、遇到故障怎么排查。六天内优先形成系统理解和可口述的答案，不以短期完成量产 BMS 为目标。

## 信息边界

- 已知：用户提供三一锂能 BMS 研究所背景和完整 JD；JD 明确强调 C/C++、RTOS、驱动、联调与测试。
- 未知：招聘主体、地点、储能或动力方向、具体模块职责、MCU/AFE 型号、RTOS 选型、面试轮次。
- 公司公开产品事实、行业通用知识、对岗位的推断在各文件中分别标明。
- 本资料中的训练题是准备建议，不是三一锂能已证实的面试原题。
- 芯片示例仅用于学习，不代表三一使用该芯片；没有把新学知识写成已有项目经历。

## 使用方式

[直接打开 CareerOS 专项面试准备](http://127.0.0.1:8765/?view=interview_prep)，或从左侧“笔面试 → 专项面试准备”进入“三一锂能 · BMS 嵌入式”。资料页支持阅读和下载；“进度与笔记”支持保存正式 JD、待确认事项、资料链接、笔记和已完成任务。
