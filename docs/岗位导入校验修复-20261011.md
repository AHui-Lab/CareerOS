# 岗位导入校验修复

以招聘个人中心页面为回归场景。用系统实际 fetch_page 读取时，页面标题和正文均仅为「个人中心」4 个字符。预览接口返回 200，原保存接口 PageImport 要求 text 至少 10 字符，导致确认保存时报 422；api() 将 FastAPI 校验数组直接传入 Error，最终出现 [object Object]。

修复：PageImport 允许短原网页正文，但仅在核对后的岗位 JD 至少有 10 个非空白字符时允许保存，保留原始抓取内容。若原网页正文与核对后 JD 都不足，返回明确的补充 JD / 招聘文字导入提示。预览来源标题限制为保存接口对应的 500 字符，前端提交旧预览来源时也兼容限制标题长度。

新增通用 API 错误格式化，支持字符串、字段校验数组和对象；按中文字段名呈现长度等错误，避免打印请求 input 原始内容。岗位导入错误在弹窗内展示，保留用户正在核对的输入。网页正文不足时，预览阶段就提示补充。

原有 72 项测试通过，随后新增真实华为响应场景并运行 4 项专门导入回归测试全部通过。独立 JS 测试覆盖错误格式化及不展示私人输入。使用独立数据库副本，完整验证同一华为地址的 4 字正文：未补 JD 显示明确错误且保留输入，补充测试 JD 后成功保存。测试未读取登录账户或提交网申。

可使用具体岗位详情链接，或者在导入核对窗口补齐实际公司、岗位和 JD。个人中心页面中的实际申请记录不在本次服务器抓取响应中，因此无法自动恢复这些岗位内容。
