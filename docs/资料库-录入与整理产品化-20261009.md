# 资料库：录入与整理流程调整

精简经历录入起点，完整资料按需展开，并在确认后用于简历。

## 新的使用流程

1. 在资料库点击“记录经历”，默认填写名称、做了什么、结果或收获。结果可稍后补充；只先保存名称也可以。
2. 保存后直接返回列表，新记录进入待整理。类型、时间、单位、角色、标签等按需要补充。
3. 打开待整理经历，补齐内容和证明材料。停止输入后自动保存，“完成”会等最后一次修改保存后退出。
4. 内容核对好后标记“可用于简历”，在对应列表中查找与复用。

## 已做的减法

- 资料库主入口只有“我的经历”和“个人资料”；分类、临时草稿、自我介绍、文件与兼容工具集中到“更多”。
- 经历列表用全部、待整理、可用于简历三个状态组织；类型改为一个筛选框。
- 所有经历类型使用同一套核心录入方式，切换类型保留输入，避免按类型重新面对一套表单。
- 卡片只展示摘要、整理状态和实际材料数量；完整内容在编辑窗口查看。
- 新增保存不再自动打开另一轮编辑；保存按钮固定在窗口底部，打开时聚焦名称。
- 经历编辑成为整页对话框，进入时暂停外围导航，退出后恢复，避免嵌入窗口内外各自操作。

## 数据边界

已有项目有简历短版时，默认编辑短版贡献与结果，完整介绍、事实、结果和备注保留在“更多资料”中。未知详情字段、相关经历、标签、既有类型与可用状态不因表单简化而清空。

新增记录默认是待整理状态，不会自动用于简历。证明材料继续保存到对应经历目录，新增查看入口使用现有本机文件服务。

分类管理、旧版导入、草稿和文件操作仍保留，位置收拢，不删除原数据或功能。

- CareerVault 20 项、JobPilot 63 项既有回归通过。
- 隔离副本实际操作验证：新增保存返回列表、补齐结果并标记可用、切换类型保留输入、修改项目短版保留完整事实、添加并查看证明材料。
- 正式页面检查完整编辑窗口、Escape 退出恢复导航和 390px 下的录入与保存按钮可见性。
