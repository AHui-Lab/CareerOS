# CareerOS 总览与渐进式界面规范

当前版本：v0.7.0。总览帮助用户看清系统各个功能区域，并找到下一步；具体模块再展开完整内容。

## 信息层级

| 层级 | 展示内容 |
| --- | --- |
| 总览 | 八个核心模块入口、简短进展、最多三项重点与近期日程 |
| 模块 | 列表、搜索、筛选与主要操作 |
| 详情 | 完整内容、材料、下一步及保存状态 |
| 更多 | 高级字段、低频工具、导入导出和配置 |

首页八个入口为岗位管理、Offer 管理、资料库、简历工作室、面试准备、笔试题库、邮件跟踪、设置与数据。点击进展可进入对应岗位筛选。完整行动计划、月历和最近岗位按需打开；进入具体记录前关闭上一层，避免叠加窗口。

## 近三天日程

- 按本地日期展示今天、明天、后天，最多三条，显示公司、日程类型、时间和简短标题。
- 支持面试、笔试、签约与 Offer 回复；点击记录看详情，“查看日历”打开完整月历。
- 超出三条时显示总数量。岗位自动生成的历史投递记录留在完整日历。
- 暂缓或归档岗位的自动提醒不占首页重点，手动录入的安排保留。
- Offer 的回复截止与签约日期从对应记录同步，修改需回到 Offer。

## 布局与验证

1280×720 和 1024×768 桌面验证中，八个功能入口直接可见，无需垂直翻页。390px 手机保持自然滚动，表格横向滚动限制在容器内部。日程测试覆盖排序、跨月、跨年和闰年；页面验证覆盖入口往返、完整月历、行动切换及快速录入。

详细页保留自然滚动，完整字段按需展开。岗位列表用于判断，详情用于处理；资料录入从三个核心字段开始；Offer 分组补充待遇。未保存编辑离开前提示，保存失败保留输入。
